# Baseline

A turn-based tennis game built for screen readers. Every shot, pick where to hit and where to cover your opponent's reply.

- Play against the computer (Easy, Normal, Hard) or a friend on the same phone
- Tiebreak, one set, best of three, or best of five
- Hard, clay, and grass courts
- Matches save automatically

Play: https://christopherabel3000-creator.github.io/New-Playbyear-Game/
